# 0002. Electron 기반 시스템 트레이 애플리케이션 아키텍처

## 배경 (Context)
화면 공간을 상시 차지하거나 브라우저 창을 계속 띄워둘 필요 없이, 2개 ChatGPT 계정의 사용량 한도를 실시간으로 확인할 수 있는 가볍고 상시 구동 가능한 모니터가 필요하다. 이 모니터는 Windows 작업표시줄 시스템 트레이 상주, 한도 임박/리셋 시 네이티브 토스트 알림 발송, 그리고 미려한 듀얼 카드 UI를 갖추어야 한다.

## 결정 (Decision)
Windows 시스템 트레이에 최소화되어 상주하는 Node.js + Electron 기반 애플리케이션으로 구현한다. 트레이 아이콘을 통해 상태를 실시간으로 암시하고, 아이콘 클릭 시 실시간 프로그레스 바와 카운트다운 타이머가 포함된 세련된 듀얼 카드 팝업을 표시하며, 한도 임계치 도달 및 리셋 완료 시 Windows 네이티브 토스트 알림을 발송한다.

## 결과 및 영향 (Consequences)
- 웹 기술(HTML/CSS/JS)을 활용하여 ChatGPT 고유의 디자인과 일치하는 고품질 UI를 구현할 수 있다.
- Windows 트레이 연동 및 네이티브 토스트 알림 API를 안정적으로 즉시 지원한다.
- 필요에 따라 로컬 브라우저에서 열 수 있는 미니 웹 엔드포인트도 손쉽게 함께 제공할 수 있다.
