# ⚡ OpenAI 사용량 모니터 (OpenAI Usage Monitor)

[![Platform: Windows](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-0078d7.svg)](https://microsoft.com/windows)
[![Node.js](https://img.shields.io/badge/node-%3E%3D18.0.0-339933.svg)](https://nodejs.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Tests: 163 passed](https://img.shields.io/badge/tests-163%20passed-success.svg)](tests/)

**OpenAI 사용량 모니터**는 Windows 작업표시줄 시스템 트레이에 상주하며, ChatGPT(Plus, Pro, Team) 복수 계정의 **실시간 사용량 한도(5시간 롤링 한도 & 7일 주간 한도)**와 **리셋 카운트다운 타이머**를 한눈에 확인할 수 있는 모던 데스크톱 애플리케이션입니다.

---

## 🌟 주요 기능 (Key Features)

### 1. 듀얼 및 N개 계정 실시간 사용량 추적
* **5시간 롤링 한도 (Primary Window):** 사용률(%) 프로그레스 바 및 1초 단위 실시간 카운트다운 타이머.
* **7일 주간 한도 (Secondary Window):** 주간 사용률(%) 및 리셋 시점 카운트다운.
* **플랜 및 계정 정보:** Plus, Pro, Team 배지 및 연동된 계정 이메일 실시간 표시.

### 2. 세션 충돌 없는 완벽한 계정 격리
* 각 계정은 독립된 프로필 디렉터리(`profiles/slotN`)를 사용하여 브라우저 쿠키 충돌이나 토큰 덮어쓰기가 전혀 발생하지 않습니다.
* 기존 OpenAI Codex CLI 세션이 PC에 존재할 경우, 첫 번째 슬롯으로 자동 연동됩니다.

### 3. 직관적인 창 제어 (핀 고정 & 드래그 이동)
* 📌 **핀 고정 모드:** 다른 창이나 바탕화면을 클릭(blur)해도 창이 닫히지 않고 화면 최상위에 떠 있도록 고정할 수 있습니다.
* **마우스 드래그 이동:** 상단 헤더 바를 마우스로 잡고 화면 어디든 자유롭게 드래그하여 배치할 수 있습니다.
* **✕ 닫기 버튼:** 핀 고정 상태에서도 원클릭으로 트레이로 숨길 수 있습니다.

### 4. 눈이 편안한 다크 / 라이트 테마
* 상단 헤더의 **☀️ / 🌙 버튼**으로 다크 테마와 모던 화이트 라이트 테마를 원클릭으로 전환할 수 있습니다.
* 선택한 테마는 설정에 저장되어 앱을 재실행해도 그대로 유지됩니다.

### 5. 유연한 계정 수명 주기 관리
* **원클릭 로그아웃:** 카드별 `[로그아웃]` 버튼을 통해 세션을 안전하게 정리할 수 있습니다.
* **간편한 계정 전환:** 로그아웃된 카드는 '미연동 상태'로 유지되어 바로 `[+ 로그인하기]` 버튼으로 다른 구글/이메일 계정으로 재연동할 수 있습니다.
* **동적 계정 추가:** 하단 `[+ 새 계정 추가]` 버튼으로 3번째, 4번째 계정을 무제한으로 확장할 수 있습니다.

### 6. 스마트 데스크톱 알림
* 사용 한도 잔여량이 설정치(기본 10%) 이하로 떨어지면 Windows 토스트 알림으로 경고합니다.
* 한도가 100% 리셋되면 충전 완료 알림을 제공합니다.

### 7. 콘솔 창 없는 네이티브 실행 환경
* 검은색 터미널 창 없이 윈도우 탐색기나 바탕화면 바로가기에서 더블클릭만으로 즉시 백그라운드 트레이에 실행됩니다.
* 작업 관리자에서도 `Electron`이 아닌 **`OpenAI_Usage_Monitor.exe`**로 깔끔하게 표시됩니다.

## 🚀 빠른 시작 (Getting Started)

### 사전 요구사항
* **OS:** Windows 10 또는 Windows 11 (64-bit)
* **런타임:** [Node.js](https://nodejs.org/) v18 이상

### 설치
```powershell
# 저장소 복제
git clone https://github.com/YOUR_USERNAME/OpenAI_Usage_Monitor.git
cd OpenAI_Usage_Monitor

# 의존성 패키지 설치
npm install
```

### 실행 방법

#### 1. 바탕화면 바로가기 생성 및 실행 (가장 추천)
```powershell
npm run shortcut
```
* 바탕화면에 전용 아이콘이 적용된 **`OpenAI 사용량 모니터.lnk`** 바로가기가 생성됩니다.
* 이후에는 터미널 없이 바탕화면 아이콘을 더블클릭하기만 하면 됩니다.

#### 2. 윈도우 탐색기에서 바로 실행
* 프로젝트 폴더에 있는 **`OpenAI_Usage_Monitor.vbs`** 를 더블클릭합니다.
* 검은 콘솔 창 없이 1초 만에 트레이에 조용히 상주합니다.

#### 3. 독립 포터블 바이너리 빌드 (`.exe`)
```powershell
npm run build
```
* `dist/OpenAI_Usage_Monitor-win32-x64/OpenAI_Usage_Monitor.exe`가 생성되며, 작업 관리자에도 `OpenAI_Usage_Monitor`로 표시됩니다.

#### 4. 개발 모드 실행
```powershell
npm start
```

## 🔒 보안 및 개인정보 보호 (Security & Privacy)

* **로컬 보안 저장소:** 모든 계정의 인증 토큰은 사용자 개인 PC의 `%APPDATA%/OpenAI_Usage_Monitor` 폴더에만 안전하게 보관됩니다.
* **외부 전송 없음:** 개발자 서버나 외부 분석 서버로 어떠한 계정 정보나 토큰도 전송되지 않으며, 공식 OpenAI 엔드포인트(`https://chatgpt.com/backend-api/wham/usage`)와만 직접 HTTPS 암호화 통신합니다.
* **독립 격리 세션:** 각 계정마다 전용 `CODEX_HOME` 프로필을 분리하여 다른 계정의 세션을 덮어쓰지 않습니다.
